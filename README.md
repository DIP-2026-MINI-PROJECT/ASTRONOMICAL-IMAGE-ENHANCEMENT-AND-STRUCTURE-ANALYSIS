# Astronomical Image Enhancement and Structure Analysis Using Digital Image Processing

## Project Description

### Summary

Astronomical images obtained through optical, infrared and X-ray observations contain structures with varying intensity distributions, contrast levels and spatial characteristics. Faint features and smaller intensity variations can be difficult to distinguish from dominant emission and background sources.

This project implements a general-purpose Digital Image Processing (DIP) pipeline for enhancing and analysing astronomical FITS images. The pipeline applies intensity transformations, spatial filtering, frequency-domain analysis and morphological operations to examine different image characteristics.

Segmentation is performed using Otsu's thresholding method on the original normalized image and the white and black top-hat responses. Connected-component analysis and feature extraction are then used to quantify the detected regions.

The results are compared through visual overlays and numerical measurements, demonstrating how different processing techniques affect the identification and distribution of image structures across astronomical datasets.

### Course Concepts Used

1. **Unit I – Digital Image Fundamentals**
   - Digital image representation and pixel intensity values.
   - Image sampling and spatial resizing.
   - Valid-pixel handling and image normalization.
   - Resizing images to a standardized 300 × 300 grid.

2. **Unit II – Image Transforms**
   - Two-dimensional Discrete Fourier Transform (DFT).
   - Frequency spectrum calculation and analysis.
   - Frequency-domain representation of images.

3. **Unit III – Image Enhancement**
   - Logarithmic intensity transformation.
   - Gamma transformation.
   - Contrast stretching.
   - Spatial filtering using Gaussian filters.
   - Frequency-domain filtering using Ideal, Gaussian and Butterworth filters.

4. **Unit IV – Morphology and Colour Image Processing**
   - Erosion and dilation.
   - Morphological opening and closing.
   - White top-hat and black bottom-hat transformations.
   - Pseudo-colour visualization.

### Additional Concepts Used

1. **Image Segmentation**
   - Otsu's automatic thresholding method.
   - Binary mask generation using intensity thresholds.
   - Mask cleanup using connected-component area filtering.

2. **Feature Extraction and Analysis**
   - Connected-component analysis.
   - Region property extraction using `regionprops`.
   - Measurement of area, centroid, bounding box, eccentricity, perimeter, solidity and other geometric properties.
   - Quantitative comparison of baseline, top-hat and bottom-hat segmentation results.

### Dataset

The project uses astronomical images stored in the FITS (Flexible Image Transport System) format.

The datasets used for testing include:

- Centaurus A – DSS optical image.
- Centaurus A – DSS2 R image.
- Centaurus A – WISE 12 μm infrared image.
- Centaurus A – RASS X-ray image.
- Crab Nebula – Planck IR image.
- Crab Nebula – DSS optical image.

The FITS files are loaded and processed individually. Invalid pixels are handled, images are resized and intensity values are normalized before further processing.

Expected input filenames:

```text
Centaurus_A_DSS.fits
Centaurus_A_DSS2_R.fits
Centaurus_A_WISE12.fits
Centaurus_A_RASS_CNT.fits
Crab_Nebula_Planck_IR.fits
Crab_Nebula_DSS.fits
```

The datasets are not generated by the project. Their original archive or download-source links should be cited alongside the corresponding FITS files when distributing the repository.

### Limitations

- A common set of processing parameters may not produce equally useful results for every astronomical image.
- Otsu's thresholding method does not guarantee accurate segmentation for images with complex or overlapping intensity distributions.
- Morphological operations depend on the selected structuring element and its size.
- Segmented regions may include background stars, noise and unrelated image structures.
- Quantitative measurements describe the detected regions but do not independently establish their physical or astronomical significance.
- The current pipeline performs image resizing but does not implement astronomical image registration or multiwavelength alignment.
